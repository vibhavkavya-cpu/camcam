# Digicam

Nostalgic iPhone 5s / early-2000s CCD digital camera app built with SwiftUI, AVFoundation, Core Image, and Metal.

## Build an Unsigned `.ipa` on GitHub (No Mac Required)
1. Upload all files in this archive to the root of a GitHub repository (`main` branch).
2. Open the **Actions** tab in GitHub and select **Build Digicam IPA**.
3. Wait for the workflow to finish, then download the **`Digicam-IPA`** artifact and unzip it to extract `Digicam.ipa`.
4. Install `Digicam.ipa` on your iPhone using SideStore, AltStore, or Sideloadly.
